# Frontend README

## Overview

This frontend powers the public website and admin interface for The Tyres Egham platform. It is built for speed, responsiveness, and a professional user experience.

## Current Frontend Stack

- React 19
- TypeScript
- Vite
- React Router
- TanStack Query
- React Hook Form
- Zod
- Tailwind CSS
- Radix UI

## Frontend Responsibilities

- Customer-facing website pages
- Tyre search and product browsing
- Brand, service, review, blog, and CMS pages
- Basket and checkout experience
- Booking confirmation and management
- Admin dashboard screens

## Main User Flows

- Browse tyres and brands
- Search by tyre size or vehicle-related flow
- Add products to basket
- Continue through checkout and booking
- Access admin pages for management tasks

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Goal

This frontend is designed to provide a clean, modern, and scalable interface that communicates clearly with the Laravel backend API.
